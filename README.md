# MV Starter Kit

Suno AIのMP3を14秒または15秒ごとのMV素材へ変換する、無料・登録不要のブラウザツールです。

公開URL: https://seiseiai1st.github.io/mv-starter-kit/

- 音源はサーバーへアップロードせず、端末のブラウザ内で処理します。
- 分割MP3、ChatGPT用シーン設計、`project.json`をZIPで保存できます。
- iPhone、Android、PCに対応しています。

この公開リポジトリには配信用の静的成果物のみを置き、開発用ソースと履歴は含めません。配信JavaScript/WASMはブラウザ実行に必要なため閲覧・解析可能です。
